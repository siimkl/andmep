# Andmepädevuse praktikumid

Viit interaktiivset andmepädevuse praktikumi ühendav veebirakendus.

Avalik rakendus: https://siimkl.github.io/andmep/

## Moodulid

- API 1: API kaudu andmete pärimise näide
- API 2: API-andmete töötlemine R-is
- API 3: keelemudeli kasutamine API kaudu
- Veebikraapimine R-is
- Treeningandmete märgendamine

## Kohalik käivitus

Käivita PowerShellis:

```powershell
.\Start-Local.ps1
```

Seejärel ava `http://127.0.0.1:8040/`.
